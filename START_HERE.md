## ❌ Troubleshooting

### "npm install doesn't work"
→ Check Node version: `node --version` should be 18.17.0+

### "Port 3000 is in use"
→ Use different port: `npm run dev -- --port 3001`

### "Styles not showing"
→ Restart dev server: `Ctrl+C`, then `npm run dev`

### "Component not found"
→ Check imports in `src/App.jsx` are correct

More help → See [SETUP_GUIDE.md](SETUP_GUIDE.md) Troubleshooting section
